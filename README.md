One line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong and makes them laugh on the way: the build did not fail because the code was broken — it failed because the tests only ever passed on a laptop that walked out of the company in March. The laptop was the CI server. The fix is implied and cheap: stop running CI on a machine with a resignation letter.

## Run it

```sh
node main.ts
```

This writes the single line to `/output/entry.txt` (155 characters, one line).
